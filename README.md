"# CampusLife" 

Приложение школьных мероприятий на Python и Kivy. Показывает ленту событий, позволяет записываться на них, получать билеты с QR-кодом и проверять их на входе. Работает на компьютере (Windows, Linux, macOS) и на Android.

## Возможности

**Лента событий**
- Список ближайших мероприятий с обложкой, датой, временем, местом и числом записавшихся.
- Поиск по названию.
- Фильтры по категории (Спорт, Творчество, Наука, Конкурсы) и по дате (любая, сегодня, неделя, месяц).
- Вкладки: все события, избранное, мои записи.

**Карточка события**
- Дата, время, место, описание, число участников, статус набора (открыт, не открыт, закрыт, мест нет).
- Запись и отмена записи, добавление в избранное.
- Напоминание о событии: без напоминания, за 1 день, за 3 дня, за неделю.
- Кнопка QR: показывает QR мероприятия и личный билет.

**QR-коды**
- QR мероприятия: содержит само событие, поэтому открывается даже на телефоне, где этого события ещё нет. Отсканировав его, можно сразу записаться.
- QR билета: содержит имя, класс и подпись. Организатор сканирует его на входе, билет проверяется на подлинность, повторный проход отклоняется.
- QR можно сохранить как картинку (папка `CampusLife_QR` в домашней папке, на Android в «Загрузки») или отправить на печать.

**Сканер QR**
- Кнопка справа вверху на главном экране.
- Распознавание через камеру (OpenCV) и поле для ручной вставки кода.

**Уведомления**
- Кнопка-колокольчик справа вверху, на ней счётчик непрочитанных.
- Типы: начался набор, скоро начнётся (за 1 час, 3 часа или сутки), событие началось, напоминание, новое мероприятие.
- Всплывающие плашки в приложении и системные уведомления (через plyer).
- Каждый тип можно включить или выключить в настройках.

**Настройки**
- Профиль: имя и класс (имя нужно для записи).
- Переключатели уведомлений, время «скоро начнётся», режим организатора.
- Адрес сервера общей регистрации и проверка связи с ним.

## Установка и запуск

```
pip install -r requirements.txt
python main.py
```

Зависимости: `kivy`, `qrcode`, `numpy`, `opencv-python`, `plyer`. Нужен именно `opencv-python`, а не `opencv-python-headless`: версия headless не умеет работать с камерой.

## Автономный режим и сервер

Без сервера приложение работает полностью автономно: все данные (события, записи, избранное, настройки) хранятся в файле `state2.json` в папке данных приложения.

Чтобы записи с разных телефонов собирались вместе, запустите сервер:

```
python server/campus_server.py
```

Он слушает порт 8000 и хранит записи в `server/regs.json`. Затем в настройках приложения укажите адрес, например `http://192.168.1.10:8000`. С сервером работают общий счётчик записавшихся, проверка лимита мест и дублей, отмена записи и единая отметка прохода по билету.

Методы сервера: `GET /ping`, `GET /counts`, `GET /list?uid=...`, `POST /register`, `POST /cancel`, `POST /checkin`.

## Режим организатора

Билеты проверяет только организатор события или пользователь с включённым режимом организатора в настройках. Остальные при сканировании билета увидят подсказку.

Подпись билетов зависит от секретного ключа (`DEFAULT_SECRET` в `campus/config.py`). Перед реальным использованием замените его на свой и используйте одинаковый ключ на всех устройствах организаторов.

## Структура проекта

```
main.py                  точка входа
camera_test.py           проверка камеры вне приложения
requirements.txt         зависимости
campus/
    app.py               приложение: состояние, уведомления, запись, QR, работа с сервером
    config.py            константы, категории, настройки по умолчанию, демо-события
    helpers.py           даты, статус набора, содержимое QR, распознавание QR
    camera.py            захват кадров с веб-камеры через OpenCV
    widgets.py           виджеты: иконки, кнопки, QR, переключатели, всплывающие плашки
    kv/                  стили и разметка экранов (.kv)
    screens/             логика экранов: feed, detail, create, settings, notifs, scan, qr
server/
    campus_server.py     сервер общей регистрации
```

## Демо-данные

При первом запуске создаются шесть примерных мероприятий (волейбол, выставка рисунков, олимпиада по информатике, робототехника, научная конференция, конкурс талантов) с датами относительно сегодняшнего дня.
